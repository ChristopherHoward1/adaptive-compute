# Architecture

_A snapshot of what the codebase IS — regenerated by `/init` and `/compact`, never hand-groomed._

## Stack

Python 3.12 (`src/` layout, numpy-only runtime) for the research code, plus the agentic-coding harness (Bash `set -uo pipefail` scripts + Markdown skills/agents). Implementer runtime is Codex; reviewers are Claude plus a Codex second reviewer (`config.yaml`). Profile: `machine-learning`.

## Layout

- `CLAUDE.md` / `ARCHI.md` / `PLAN.md` — the hot tier (~300-line budget).
- `config.yaml` — profile, per-role models, implementer runtime, gate command + required tools (`shellcheck`), worktree dir (`../adaptive-compute-worktrees`).
- `src/adaptive_compute/` — `metrics.py` (AUC, paired `Δ`); `generators.py` (five-member frozen synthetic battery); `bootstrap.py` (draw-accounted paired resampler, `SeedSequence.spawn` branches); `reference.py` (fixed-budget percentile-bootstrap decision); `adaptive.py` (blind adaptive controller, empirical-Bernstein CS); `betting.py` (WSR betting CS, selectable via `instrument="eb"|"betting"`); `sweep.py` (fixed-B sweep + Pareto); `benchmark.py` (offline adaptive-vs-reference harness); `strata.py` (plug-in `Δ(E)` strata); `equiv_probe.py` (equivalence-band probe); `eval.py` (CLI).
- `tests/` — `test_*.py` per module plus `test_determinism.py` / `test_smoke.py`; `test-scripts.sh` is the harness shell smoke suite.
- `docs/` — `research-definition.md`, `prior-art.md`, `experiment-design.md`.
- `pyproject.toml` — metadata + ruff (`E,F,I` + format), pytest (`pythonpath=["src"]`), mypy.
- `skills/` — loop stages `1-plan`…`5-retro` plus `init`, `compact`; exposed via `.claude/skills → ../skills`.
- `.claude/agents/` — `plan-reviewer`, `code-reviewer`, `fan-selector` (read-only, separate model).
- `scripts/` — `gate.sh`, `worktree.sh`, `agent-exec.sh`, `fan-exec.sh`, `codex-review.sh`, `release.sh`, `state.sh`, `archi-fresh.sh`. `worktree.sh`/`codex-review.sh` bound `git fetch origin` under `timeout`/`gtimeout` (`WORKTREE_FETCH_TIMEOUT`, default 30s) when available. `gate.d/*.sh` hooks: `test-scripts.sh`, `py-quality.sh`, `eval.sh`, `ds-hygiene.sh`, `nb-clean.sh`; `gate.d/examples/` holds un-enabled originals.
- `profiles/` — `software` / `machine-learning` (active) / `database` / `work`.
- `VERSION` / `CHANGELOG.md` — CalVer + Keep-a-Changelog, written only by `release.sh`.
- `work/<slug>/` — work units (plan, handoff, reviews, results, retro); `work/.last-released`.
- `knowledge/` — cold-tier docs, loaded only on citation.
- `.github/workflows/ci.yml` — shell smoke suite + gate on push/PR. `AGENTS.md` — the implementer's contract.

## Entry points

- **The loop:** `/1-plan` → `/2-implement` → `/3-review` → `/4-release` → `/5-retro`, invoked as skills.
- **`scripts/gate.sh`** — auto-detects stacks (Python + Shell), runs checks + `gate.d/` hooks. Exit 0 = pass.
- **`python -m adaptive_compute.eval`** — `--check` (gate self-check), `--run` (v0 benchmark → `work/adaptive-procedure/results.*`), `--compare` (EB vs betting A/B), `--equiv-probe` (equivalence-band probe). All but `--check` are offline, outside the gate.
- **`scripts/release.sh <slug>`** — local divergence: `tag-after-merge` tags the release commit found by its `VERSION` transition on `origin/main` (any merge strategy), guarded by `origin/main:VERSION == version`.

## Conventions

- Writer never reviews; gate and release are authoritative scripts; implementation only in worktrees; vendor/model names only in `config.yaml`.
- Shell must pass `shellcheck`; Python must pass `ruff check`, `ruff format --check`, `mypy src`, `pytest`.
- Notebooks are exploratory-only; correctness-critical logic lives in gated `.py`; tracked notebooks must be output-stripped.

## Verification

`bash scripts/gate.sh` — `shellcheck` preflight + lint over tracked `*.sh`, `ruff check .`, `pytest -q` (one `-p no:capture` retry if pytest dies by signal), then `gate.d/` hooks. CI runs the gate on push.

### ML profile declarations

- **EVAL_METRIC** — decision agreement vs the fixed-budget reference, per-stratum false-stop rate (binomial CI), draws p50/p90/p99, abstain rate, reference-unresolved count, fixed-B Pareto savings.
- **GROUND_TRUTH_SOURCE** — plug-in `Δ(E)` on the frozen set for strata/expected decisions; the reference is the full-budget same-procedure conclusion, not truth.
- **EVAL_COMMAND** — `python -m adaptive_compute.eval --check` via `scripts/gate.d/eval.sh`.
- **DATA_REGIME** — offline fixed sets from the five-member battery (near-δ-boundary, small-effect, heavy-tailed, rare-event, easy/lopsided).
- **NOTEBOOK_STRATEGY** — exploratory-only under `notebooks/<initials>/`; `nb-clean.sh` enabled.
- **REPO_HYGIENE** — `ds-hygiene.sh` defaults (`DS_DATA_MAX_BYTES=1048576`, `DS_DATA_ALLOW_DIRS=tests/fixtures`, `DS_PATH_SCAN=1`).
