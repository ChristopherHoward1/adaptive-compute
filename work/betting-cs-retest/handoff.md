## What this unit is

Re-test a prior scientific result under a tighter statistical instrument, as a controlled A/B. The released v0 procedure (`adaptive.py`) grows Monte-Carlo bootstrap draws under a finite-horizon **empirical-Bernstein (EB)** confidence sequence on the bounded mean `E*[Δ*]` (each draw `Δ* ∈ [-1,1]`) until the band resolves a decision (`A_better`/`B_better`/`equivalent`) or abstains at `B_max`. That gave a genuine H1 NEGATIVE: zero false stops (§7 PASS) but it fails §8's ≥2× savings gate — the EB band is too loose, so median draws (448 moderate / 768 equivalent) exceed the whole fixed-B grid. This unit adds a **Waudby-Smith–Ramdas (WSR) betting confidence sequence** as an alternative, tighter band and re-runs §7/§8 to see whether the savings verdict flips. Read `knowledge/anytime-valid-band.md` in full — it explains the estimand, why the mean is the target, the abstain-vacuity trap, and the B_max sizing rule.

## Key constraints

1. **Same stream, only the band changes — `b` is a shared constant.** `adaptive_bootstrap_stream` (bootstrap.py) generates each batch with `rng.integers(0, n, size=(b, n))`; a different `b` shifts RNG call boundaries so the per-draw deltas would differ. Both arms must run with the SAME `b` (pin the current `b=64`) so the drop-in equivalence is exact and the A/B is uncounfounded. Only `B_max` may differ between arms. `test_betting.py` must assert this equivalence with `np.array_equal` on matched-prefix batch deltas.

2. **WSR construction (faithful + anytime-valid).** Rescale `Δ* ∈ [-1,1]` to `X = (Δ*+1)/2 ∈ [0,1]`; build the CS for `μ_X ∈ [0,1]` and map back by `2·[l,u]-1`. Over a grid `m ∈ [0,1]`, maintain two-sided hedged capital `K_t(m) = ½(K⁺_t + K⁻_t)`, `K±_t = ∏_{i≤t}(1 ± λ_i(m)(X_i - m))`, with a **predictable** betting fraction `λ_i(m)` from the running mean/variance of `X_{<i}` ONLY (WSR approx-GRAPA plug-in, truncated to a valid range e.g. `[0, c/(m∨(1−m))]`, `c<1`). CS = `{m : max_{s≤t} K_s(m) < 1/α}`; bounds = min/max surviving grid points. No `max_looks` union bound — Ville's inequality gives time-uniformity for free. **Predictability (λ from past only) + the running-max are what make it valid — get these right.** Make the grid fine enough near `±δ` (δ=DEFAULT_DELTA=0.05) that an `equivalent` decision (band wholly inside `[−δ,δ]`) can resolve.

3. **Deterministic, load-bearing tests** in `test_betting.py`: (a) **predictability** — the bound at time `t` is unchanged when draws after `t` are permuted/altered; (b) **capital sanity** — under a null stream centered at `m`, `K_t(m)` behaves as a nonnegative martingale (`E[K_t]≈1`, no spurious `1/α` crossings) on a fixed `SeedSequence`; (c) **coverage sanity** — fixed `SeedSequence`, named `N`, observed miss count ≤ an explicit hard integer bound (betting is conservative, pick with margin — non-flaky); (d) **rescale round-trip**; (e) **drop-in stream equivalence** (constraint 1); (f) **resolves-faster-than-EB on an `equivalent`-stratum case** — at a matched seed/stream, betting reaches the correct `equivalent` decision in STRICTLY fewer draws than EB. The `equivalent` case is required (that's where the v0 negative lived); `easy_lopsided` optional.

4. **Do not overrule the gate.** `scripts/gate.sh` runs shellcheck + `ruff check` + `ruff format --check` + `mypy src` + `pytest -q` + `gate.d/` hooks (including `eval --check`). Everything Python must pass all of ruff/mypy/pytest. New code is numpy-only (no new dependencies).
