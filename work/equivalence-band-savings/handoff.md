## What this unit is

Resolve the last-standing H1 savings negative: whether *any* adaptive instrument beats a single fixed-B when the truth sits inside the equivalence band `[−δ,δ]`. Two released results (EB v2026.9.3, betting v2026.9.4) narrowed the negative to the `equivalent` stratum alone. This unit adds an **offline probe** (`eval --equiv-probe`) that diagnoses the current stratum's homogeneity and tests a deliberately heterogeneous, reference-resolvable in-band population under both instruments.

**Corrected mechanism you must respect (do not re-derive the wrong version):** equivalence budget is *position-dependent*, not fixed — to conclude `equivalent`, the WHOLE CS interval must lie in `[−δ,δ]`, so a case at `|Δ|=δ−ε` needs half-width ≲ ε and gets sharply harder toward the band edge. The current `equivalent` stratum only *looks* homogeneous because the `small_effect` generator clusters `|Δ|≈0.02`. The probe tests whether real position heterogeneity changes the verdict.

## Key constraints (controlled-retest discipline — read knowledge/controlled-retest-discipline.md)

1. **You cannot reuse `run_benchmark`/`_run_member_seed`** — both iterate `BATTERY` and `generate()` raises `ValueError` on an unregistered name (`generators.py:164-169`). The probe supplies its OWN per-case driver replicating `_run_member_seed`'s pipeline: `generate(fixture case) → fixed_budget_reference(...) → adaptive_decision(..., instrument=…) → fixed_b_sweep(...)`, building `MemberRun` objects, then reuse `benchmark._summarize_stratum(list[MemberRun]) → sweep.pareto_verdict`. Do NOT reimplement Pareto/savings arithmetic.
2. **Resolvability precheck is load-bearing (finding 2).** With `DEFAULT_DELTA=0.05`, `classify_delta`'s boundary band is `ρ·margin=0.005` so `|Δ|≥0.045` is reclassified `boundary` and dropped from non-boundary strata; and at `DEFAULT_B_REF=320` a near-edge case is likely `reference_unresolved` and dropped from `scored`. So the engineered hard/shallow half is exactly the half scoring can silently discard → a FALSE no-flip. Before scoring, the probe must PROVE a non-empty "resolvable-yet-hard" region: cases that are `equivalent`-classified (not `boundary`) AND reference-resolved at `B_ref=320`, whose shallow tier needs strictly more reference draws than the deep tier. Place the shallow tier at the hardest `|Δ|` that still clears both with margin — not blindly at `δ−ε`. If the region is empty, `verdict.md` must say so and frame the finding as *reference-resolving-power, not adaptivity*.
3. **Pin the adaptive knobs in code and assert them (finding 3).** Both arms use `b=64` and a PINNED `b_max` constant (asserted equal across arms in code — not tuned; the probe does not go through the benchmark tuner). Report the abstain/nondecision rate alongside savings in the JSON. `pareto_verdict` also requires `adaptive_nondecision_rate ≤ fixed_nondecision_rates[b]` (`sweep.py:123-126`), so too-small `b_max` makes shallow cases abstain and blocks domination even at low median — pick `b_max` large enough that resolvable cases resolve, and justify it in a comment.
4. **Diagnostic Δ is recomputed by regeneration (finding 5):** `MemberRun` does not store `Δ`. Recover it via `metrics.delta(*generate(replace(BATTERY[member][0], seed=run.seed)))` (stored `seed` == `params.seed + seed_index`). Keep the diagnostic minimal — it is near-circular (the `equivalent` stratum is almost all `small_effect`), framed only as "the natural stratum is generator-homogeneous," and carries none of the verdict.
5. **Verdict is mechanically derived + stability-checked (finding 3/7):** the `verdict.md` one-line headline is computed from the JSON fields (as `_compare` does at `eval.py:307-316`), not hand-written, and must hold across ≥2 deep:shallow mixture ratios; a ratio-sensitive flip is reported as a fixture-tuning artifact, not a win.
