# knowledge/ — the cold tier

On-demand reference docs. Started empty on purpose; each doc below exists because a session needed it.

A doc is written here only after a session demonstrably needed it and it didn't exist — an agent re-derived something expensive, or got something wrong that a spec would have prevented. Write the doc that would have prevented that instance, no bigger.

Load a doc only when a task names it. Nothing in this directory is hot context.
