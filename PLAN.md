Novelty claim narrowed to an *application + empirical* result over Gandy (2009) et al. — `docs/prior-art.md`.
- 2026-09-19 — **Architecture: one repository** for adaptive validation + adaptive explainability (they share the "grow MC draws under an anytime-valid band until a decision resolves" controller), but the **shared abstraction stays un-scaffolded** until the explainability consumer exists. **Dynamic inference routing is deferred, likely a separate repo** (per-input, streaming, regime-A methodology — not the MC-budget primitive). Revisit if v0/v1 shows the controller genuinely reused. — `docs/research-definition.md` §5, `docs/prior-art.md`.
- 2026-09-19 — ML declarations EVAL_METRIC / GROUND_TRUTH_SOURCE / DATA_REGIME set PROVISIONAL (not resolved) pending the reference unit; EVAL_COMMAND stays PENDING until code exists.

Caught by the plan reviewer; Owner-confirmed. — `work/adaptive-procedure/plan.md`, `knowledge/anytime-valid-band.md`.

A tighter betting CS could resolve at far smaller budgets and flip the savings verdict. Do not generalize to "adaptivity does not save compute" until the betting-CS re-test (Next). — `work/adaptive-procedure/retro.md`.
- 2026-09-22 — **Betting-CS re-test: the negative narrows, it does not reverse.** A tighter WSR betting CS cuts median draws 2–5× and passes §8 in the easy and moderate strata, but the **equivalent stratum still fails** (fixed-B resolves equivalence cheaply and dominates). - 2026-09-22 — **Controlled re-test discipline** (`knowledge/controlled-retest-discipline.md`): a unit that re-tests a released result under a swapped component must give the experiment its own parameterized entry point (never mutate the released `--run` path's defaults), pin the shared variable in code (not by lucky tuning selection), never overwrite the released artifact, and write guard-tests that can actually fail. Ignoring the first rule cost `betting-cs-retest` rounds 3–5. — `work/betting-cs-retest/retro.md`.

Interim: fix to a genuine dual-APPROVE (or Owner-authorized bypass). Durable fix = `/1-plan` `release-anchor-approve-path`. — `work/betting-cs-retest/retro.md`.
- 2026-09-22 — **Experiment plans must state a detectability precondition and load the governing cold doc at plan time.** A `/1-plan` unit that proposes an experiment to *detect* an effect must state, and its plan-reviewer must check, that the comparison/measurement can actually **express** the sought effect (e.g. the baseline grid must contain a budget the treatment could beat), and must load the governing `knowledge/` doc. `equivalence-band-savings` cost a full implement+review cycle (rev-1, approved) and an unsound "fair test" (rev-2) because the fixed-width-functional property — already in `knowledge/anytime-valid-band.md` — was not applied at plan time; a grid capped at `B_ref` could not express the flip the experiment sought. — `work/equivalence-band-savings/retro.md`.
- 2026-09-22 — **Equivalence-band question closed: the savings negative is structural, not a tuning/grid artifact.** Inside `[−δ,δ]` the fixed-B percentile interval is a fixed-width functional that certifies equivalence at `B*≤~B_ref`, while any anytime-valid CS must shrink MC error below δ — so fixed-B dominates both instruments (per-instrument `b`). Adaptive MC-budget savings are a **directional**-decision story only. Do not re-open in-band savings; a directional positive-result unit is the live thread. — `work/equivalence-band-savings/retro.md`, `knowledge/equivalence-band-savings.md`.

- 2026-09-23 — **A plan's `Plan verdict: APPROVE` is recorded only from a fresh plan-reviewer's APPROVE of that revision.** After applying REVISE findings, the verdict stays `REVISE` until a fresh re-review. The Orchestrator never writes APPROVE on its own revision, because `state.sh` trusts the sentinel line whoever wrote it. — `work/gate-readline-resilience/retro.md`.
- 2026-09-23 — **Read CI state from `gh pr view <n> --json statusCheckRollup,mergeStateStatus`, never from the tail of `gh pr checks --watch`.** The watcher can die on a network error and leave a stale `pending` as its last line (seen twice). — `work/gate-readline-resilience/retro.md`.

## Risks

- **Novelty is thin by design.** The stopping guarantee is Gandy (2009) / confidence sequences; our contribution is empirical (savings + uniform false-stop on equivalence-band comparison). If that residual collapses under a closer reading, narrow the question — don't inflate it. — `docs/prior-art.md`.
- **Most-likely negative result:** the anytime-valid band is too conservative, `B_max` is hit often, and savings evaporate. Acceptable as a finding; the fixed-B Pareto baseline is built to detect it. — `docs/research-definition.md` §8.
