## Decisions

Older decisions: `knowledge/decisions.md`.

- 2026-09-19 — Close-out shape for **spec-only / Orchestrator-authored units**: they produce only one review sentinel, so `scripts/release.sh` (two-sentinel precondition) cannot run — close them via a plain PR to `main`, no CalVer bump. If such units recur, spin a `/1-plan` unit to teach `release.sh` a single-review close-out path. — `work/research-bootstrap/retro.md`.
- 2026-09-19 — **Reviewer calibration norm.** When the two `/3-review` reviewers split, the integration `code-reviewer` is the calibration anchor (its own contract: blocking on LOW-only findings is miscalibration); Codex tends to REQUEST CHANGES on latent/cosmetic items. Genuine design splits go to the Owner to arbitrate; otherwise ship on the integration reviewer's APPROVE with the latent items written to `deferrals.md`. Do not churn the implementer round-after-round on non-live findings. — `work/fixed-budget-reference/retro.md`.
- 2026-09-20 — **`tag-after-merge` tags only the release *current* on `main`** (currency guard `origin/main:VERSION == version`) — deliberate; a tag missed until after a newer release ships needs a manual `git tag`. The loop tags immediately post-merge, so this holds in normal flow. Automatic back-tagging, if ever wanted, is a separate unit that relaxes this guard. — `work/release-tag-merge-commit/retro.md`, `knowledge/release-tagging.md`.
- 2026-09-20 — **Adaptive band instrument = empirical-Bernstein confidence sequence on the bounded mean `E*[Δ*]`** (§3's literal instrument), not a tail-probability CS. The tail-prob CS's bounded 0/1 indicators are immune to tail heaviness, which would neuter the §6 heavy-tail member and let H1 pass §8 trivially; the mean CS keeps heavy tails adversarial and still agrees with the reference on all non-`boundary` battery cases (battery built so reference verdict == `decision_from_delta`). Caught by the plan reviewer; Owner-confirmed. — `work/adaptive-procedure/plan.md`, `knowledge/anytime-valid-band.md`.
- 2026-09-22 — **Betting-CS re-test: the negative narrows, it does not reverse.** A tighter WSR betting CS cuts median draws 2–5× and passes §8 in the easy and moderate strata, but the **equivalent stratum still fails** (fixed-B resolves equivalence cheaply and dominates). So the residual savings-negative is specifically about equivalence-band decisions, not adaptivity in general. — `work/betting-cs-retest/retro.md`.
- 2026-09-22 — **Controlled re-test discipline** (`knowledge/controlled-retest-discipline.md`): a unit that re-tests a released result under a swapped component must give the experiment its own parameterized entry point (never mutate the released `--run` path's defaults), pin the shared variable in code (not by lucky tuning selection), never overwrite the released artifact, and write guard-tests that can actually fail. Ignoring the first rule cost `betting-cs-retest` rounds 3–5. — `work/betting-cs-retest/retro.md`.
- 2026-09-22 — **`release.sh`'s two-APPROVE precondition structurally conflicts with the ship-on-anchor calibration norm.** When Codex re-flags a non-live item the anchor has cleared, the norm says ship on the anchor — but `release.sh` hard-requires an exact `Codex-review verdict: APPROVE`, so ship-on-anchor cannot pass the versioned release, forcing fix rounds purely to appease Codex. Interim: fix to a genuine dual-APPROVE (or Owner-authorized bypass). Durable fix = `/1-plan` `release-anchor-approve-path`. — `work/betting-cs-retest/retro.md`.
- 2026-09-22 — **Experiment plans must state a detectability precondition and load the governing cold doc at plan time.** A `/1-plan` unit that proposes an experiment to *detect* an effect must state, and its plan-reviewer must check, that the comparison/measurement can actually **express** the sought effect (e.g. the baseline grid must contain a budget the treatment could beat), and must load the governing `knowledge/` doc. `equivalence-band-savings` cost a full implement+review cycle (rev-1, approved) and an unsound "fair test" (rev-2) because the fixed-width-functional property — already in `knowledge/anytime-valid-band.md` — was not applied at plan time; a grid capped at `B_ref` could not express the flip the experiment sought. — `work/equivalence-band-savings/retro.md`.
- 2026-09-22 — **Equivalence-band question closed: the savings negative is structural, not a tuning/grid artifact.** Inside `[−δ,δ]` the fixed-B percentile interval is a fixed-width functional that certifies equivalence at `B*≤~B_ref`, while any anytime-valid CS must shrink MC error below δ — so fixed-B dominates both instruments (per-instrument `b`). Adaptive MC-budget savings are a **directional**-decision story only. Do not re-open in-band savings; a directional positive-result unit is the live thread. — `work/equivalence-band-savings/retro.md`, `knowledge/equivalence-band-savings.md`.
- 2026-09-23 — **A plan's `Plan verdict: APPROVE` is recorded only from a fresh plan-reviewer's APPROVE of that revision.** After applying REVISE findings, the verdict stays `REVISE` until a fresh re-review. The Orchestrator never writes APPROVE on its own revision, because `state.sh` trusts the sentinel line whoever wrote it. — `work/gate-readline-resilience/retro.md`.
- 2026-09-23 — **Read CI state from `gh pr view <n> --json statusCheckRollup,mergeStateStatus`, never from the tail of `gh pr checks --watch`.** The watcher can die on a network error and leave a stale `pending` as its last line (seen twice). — `work/gate-readline-resilience/retro.md`.
- 2026-09-23 — **The adaptive mean-CS procedure estimates a closed-form quantity; a zero-draw rule dominates it.** `E*[Δ*]` equals the plug-in `Δ(E)` up to bootstrap bias (median gap 0.00025, max 0.0018). `decision_from_delta(Δ(E))` matched the reference on 586/586 scored held-out cases. Fixed-B at `B=32` agrees on 99.4% of directional cases. So the "directional positive" does not exist as posed. Pooling strata would pass §8 only through a functional mismatch on 0.4–0.6% of cases, which would be a strawman. Found at plan time by the detectability precondition; no unit spent. — `knowledge/anytime-valid-band.md`, `docs/research-definition.md` §7.
- 2026-09-23 — **SHAP top-k adaptive savings are marginal; the unit was withdrawn at plan stage.** Prototype at D=12, |bg|=64, n=40, natural case mix, shared stream, fixed-horizon certified baseline. Adaptive mean cost 7,119 draws with 17.5% abstain. Certified fixed-M needs 16,384 draws (about 2.3×). With exact fallback, adaptive costs 0.53 of exact enumeration. Uncertified fixed-M at 4,096 is cheaper and was never wrong. Ties drive the cost. This is the third setup where certifying costs more than being right. — `knowledge/shap-topk-savings.md`, `work/shap-topk-savings/plan.md`.
